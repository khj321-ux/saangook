# 이미지 관리

웹사이트 이미지는 이 폴더에서 관리합니다.

- `home/`: 홈 대표 이미지
- `space/`: 공간 및 시설 사진
- `programs/`: 프로그램별 대표 이미지와 추가 이미지
- `archive/`: 향후 프로그램 외 아카이브 콘텐츠 이미지

프로그램 폴더명은 영문 소문자, 숫자, 하이픈만 사용합니다. 프로그램별 폴더 안에서는 대표 이미지를 `main.jpg`, 추가 이미지를 `01.jpg`, `02.jpg`, `03.jpg` 순서로 관리합니다.

예시:

```text
programs/bookclub-nietzsche/
├── main.jpg
├── 01.jpg
├── 02.jpg
└── 03.jpg
```

실제 화면에 표시할 경로는 `assets/data.js`의 `site.images` 또는 각 프로그램의 `images`에서 지정합니다. 같은 경로와 파일명을 유지한 채 사진 파일만 교체하면 코드 수정 없이 새 사진이 표시됩니다.
